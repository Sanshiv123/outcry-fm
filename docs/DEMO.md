# Three-minute demo

1. Start the server, press Play, show the SIMULATED label if in mock mode.
2. Create a fresh account. Show the wallet and the explicit mode label.
3. Select Buy $1 SOL; review the Gateway-derived amount and fee, then confirm.
4. Show the shared board and The Wire with the simulated/real order ID.
5. Call the floor, type or say “buy 500 SOL”. Show the backend refusing the cap.
6. Buy another $1 SOL, then tip $1 SOL. Fees mean the first $1 buy alone does not
   leave enough SOL for a full $1 tip. Confirm the tip and show its verified row.
7. The next shared show segment announces recent verified activity.

For live voice, configure the private ElevenLabs agent first. If the call is
unreliable, use the push-to-talk or typed order and tap confirmation. Never call a
simulated transaction real. Record a backup demo after the real integration is
verified. No backup video or public submission has been created automatically.
